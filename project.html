Multi-Site Shopify Migration - Fuel Cell Store

Sep 2026 - Present
ShopifyOpenCartWordPressMySQLAI Reverse EngineeringIn Progress

Migrating the company's three sites to separate Shopify stores. The first, the HTEC Education store, has moved off OpenCart 3 and is now live. The largest, the Fuel Cell Store storefront on OpenCart 3.0.3.8, carries a 2,000+ SKU catalog and the order history from the previous platform upgrade. It is still in progress, along with the Fuel Cells Etc site on WordPress.

Owning the data migration: mapping two OpenCart databases and a WordPress site onto Shopify's data model, and moving each site's products, customers, and order history into its new store.

Working from the existing code rather than documentation, using AI-assisted reverse engineering to reconstruct what each custom module and template override actually does, and building a migration plan from that before writing any Shopify code.

Deciding feature by feature how to carry over custom functionality with no direct Shopify equivalent: an app, a native capability, or a custom build.

Rebuilding each site's theme on Shopify and mapping legacy URLs to their new addresses so all three sites keep their search rankings.

Warehouse & Inventory Subsystem (WMS) - Fuel Cell Store

Oct 2024 - Present
PHPSQL ServerLinuxWMSLot TraceabilityQR Scanning

Built the warehouse and shop-floor half of the internal operations platform, alongside the ERP: stock, receiving and purchase orders, builds and bills of materials, waste, and physical counts across 2,000+ SKUs.

Moved shop-floor work to scanning: operator badges, work orders, SKUs, and material lots are all identified by QR code, through either a hardware barcode gun or the browser camera.

Added a discrepancy lock: when a physical count does not match the database, the SKU is blocked from pulling until the variance is resolved, so a quantity already known to be wrong stops moving.

Rebuilt the lot-tracked materials subsystem from the ground up on its own database, retiring an unreliable legacy version without putting live inventory at risk.

Built directly on the ERP's SQL Server schema rather than behind a sync layer, so stock reads and writes are immediate and cannot drift out of step with orders, and stock lookups and inventory reports return in under a second.

Mar 2024 - Sep 2024
OpenCartPHPMySQLTwigSQL MigrationReconciliation

Led the company's e-commerce migration from OpenCart 1.5.6.4 to 3.0.3.8, covering 2,000+ SKUs and 70,000+ historical orders, reconciled table by table, with no business interruption.

Wrote SQL migration scripts for data cleaning, field mapping, and relationship rebuilding across major version differences.

Internal Operations Platform (ERP / WMS / MES) - Fuel Cell Store

Aug 2023 - Present
PHPSQL ServerLinuxERPWMSMES

Designed and built the company's internal operations platform as sole developer, replacing a slow, partial VB.NET WinForms desktop system with one web platform covering orders, inventory, materials, production work orders, and shipments.

Modeled the business in a 50+ table SQL Server schema shared directly with the warehouse subsystem, used by 20 to 30 internal users at the same time; its audit table has passed 1,000,000 rows.

Built 40+ reports that query live operational data and return in under a second, with no separate analytics stack to build or keep in sync.

Prevented conflicting edits with work-order locking shared with the warehouse subsystem, and added a unified audit trail recording who changed what across every module.

Implemented scheduled backups and recovery workflows to reduce system recovery time to minutes.
